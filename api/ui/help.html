Ollama Modelfile

Shows the model configuration returned by Ollama. This is read-only.

Equivalent CLI command
ollama show --modelfile qwen3:4b

SYSTEM, TEMPLATE, PARAMETER and ADAPTER are separate Modelfile instructions. Not every model contains every section.
